⚙️ Guide d'administration – AutoPrime

Gérez votre stock de voitures facilement depuis Google Sheets

Comment ça fonctionne ?
Votre site lit automatiquement votre Google Sheet à chaque visite. Dès que vous ajoutez, modifiez ou supprimez une voiture dans le tableau, le site se met à jour pour tous vos visiteurs — sans toucher au code.

Étape 2 – Rendre le Sheet public

Étape indispensable ! Sans ça, le site ne pourra pas lire vos données.
1

Cliquez sur le bouton « Partager » en haut à droite de Google Sheets

2

Cliquez sur « Modifier » à côté de "Accès restreint"

3

Sélectionnez « Tous les utilisateurs disposant du lien »

4

Assurez-vous que le rôle est « Lecteur » (pas Éditeur)

5

Cliquez sur « OK » pour confirmer

Étape 4 – Ajouter / modifier des voitures

Une fois configuré, c'est aussi simple que de remplir un tableau Excel. Chaque ligne = une voiture.
➕

Ajouter une voiture : Ajoutez une nouvelle ligne dans le tableau avec toutes les informations. Le site l'affichera automatiquement.

✏️

Modifier une voiture : Modifiez directement la cellule concernée. Le changement sera visible sur le site à la prochaine visite.

🗑️

Supprimer une voiture : Supprimez la ligne entière. Ou mettez Non dans la colonne "dispo" pour l'afficher comme "Vendu".

📸

Ajouter une photo : Mettez l'URL directe d'une image dans la colonne "photo". Vous pouvez héberger vos photos sur imgur.com ou cloudinary.com gratuitement.

Questions fréquentes

❓ Le site ne charge pas mes voitures ?

Vérifiez que : (1) le Sheet est bien public, (2) l'onglet s'appelle exactement "Voitures", (3) le Sheet ID est correct dans script.js

❓ Combien de temps avant que les changements soient visibles ?

Immédiatement ! Le site recharge les données à chaque visite. Actualisez simplement la page du site.

❓ Puis-je avoir plusieurs photos par voiture ?

Pour l'instant, une seule photo principale est supportée. Mettez l'URL de la meilleure photo.

❓ Où héberger mes photos de voitures ?

Gratuitement sur imgur.com (glissez-déposez la photo → copiez le lien direct). Ou sur cloudinary.com pour plus de contrôle.

❓ Le Google Sheet est-il sécurisé ?

Les visiteurs peuvent lire les données (c'est voulu), mais ils ne peuvent pas les modifier. Seul vous (connecté à votre compte Google) pouvez éditer le tableau.
